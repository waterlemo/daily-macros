# 一日三量

手机端饮食记录工具。设置碳水、蛋白质和脂肪的每日目标，查看当天的已摄入、剩余或超出量。支持输入实际摄入量、按每 100 克换算、临时计算、常用食物和按日期回看。

在「管理目标」设置每天自动沿用的默认目标，也可以新增、修改和删除命名方案，例如训练日和休息日。用「今日目标」把方案应用到当前日期。这一天会保留应用时的数值，之后修改或删除方案不会改变已保存的当日目标。可以随时重新应用方案或改用默认目标。

「存为常用」支持按每 100 克保存和直接保存摄入量。点选前者后填写实际份量，点选后者会直接填入保存的碳水、蛋白质和脂肪克数。

## 在 iPhone 上打开

在 Safari 打开[一日三量](https://waterlemo.github.io/daily-macros/)，选择「口令登录」即可查看并同步记录。也可以通过 Safari 分享菜单把网页添加到主屏幕。

## 本机试用

在项目目录运行 `python -m http.server 8000 --bind 127.0.0.1 --directory docs`，然后在浏览器打开 `http://127.0.0.1:8000/`。只做换算可以直接使用。选择「在本机试用」后，试用记录保存在当前浏览器。同步账户中的记录独立存储。

## 部署同步接口

[GitHub Pages](https://waterlemo.github.io/daily-macros/) 从 `main:/docs` 发布网页。腾讯云北京 SCF 校验网页口令，并和私有 COS 同步目标、常用食物及每日记录。

1. 运行 `npm ci --omit=dev` 和 `python deploy/build-scf-zip.py daily-macros-scf.zip`。在腾讯云北京地域为 `daily-macros-api-node20` Web 函数选择 Node.js 20.19 并上传 ZIP。启动脚本使用端口 9000。
2. 配置独立的私有 COS 桶，保留默认的未开启版本控制状态。为函数绑定独立运行角色，允许列出该桶，以及读取和创建 `nutrition/` 前缀中的对象。
3. 为函数启用 HTTPS 公网函数 URL，应用校验数据请求的登录状态并处理 CORS。访问函数 URL 加 `/health`，应返回 `{"ok":true}`。
4. 配置下表的环境变量。用安全随机数生成个人口令，在本地计算其 SHA-256，向函数配置填入散列。另生成独立的 32 字节随机会话密钥并编码为 Base64URL。更换口令时一并更换会话密钥，原有会话随之失效。

| 名称 | 内容 |
| --- | --- |
| `SITE_URL` | GitHub Pages 首页 HTTPS 地址 |
| `COS_BUCKET` | 饮食记录的私有 COS 桶名，包含 APPID |
| `COS_REGION` | COS 桶所在地域，目前为 `ap-beijing` |
| `PASSPHRASE_HASH` | 个人口令的 SHA-256，小写十六进制 |
| `SESSION_KEY` | 32 字节随机密钥，Base64URL 编码 |

5. 验证函数拒绝未登录的读写请求。将 `docs/config.mjs` 的 `apiUrl` 指向函数的 HTTPS 地址并发布。手机和电脑分别用同一个口令登录，写入并读回一条记录。

口令仅在登录时通过 HTTPS 发送。从成功登录起，同一浏览器可保留 30 天的会话，关闭网页后再打开也能恢复。网页删除会移除当前记录，私有 COS 会保留旧版本以协调并发更新。
